# Number Guessing Game
A simple Python game where the player tries to guess a randomly generated number between 1 and 10. This project was created to practice Python fundamentals, including loops, conditional statements, user input, exception handling, and the random module. 
The program generates a random number between 1 and 10 and keeps asking the player to guess until they get the correct answer.
# Python Concepts Used
- random module
- while loops
- if-else statements
- User input 
- Type conversion
- Exception handling
